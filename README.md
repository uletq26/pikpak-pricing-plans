## **無料プランで何ができて、何ができないのか**

「無料で使える」と聞くと、どこかに落とし穴があるんじゃないかと思う。実際のところを整理しよう。

無料プランで使えること：
- 6GBのプライベートクラウドストレージ
- URL・共有リンクからのクラウド保存（基本機能）
- 保存したファイルのブラウザ・アプリでの閲覧
- Android / iOS / Windows / Mac / Web対応

無料プランでできないこと・制限されること：
- ストレージが6GBと少ない（10TBのPremiumに比べると圧倒的に少ない）
- ダウンロード速度が遅め
- 4K動画のオンライン再生は不可
- Torrent/Magnetリンクからのクラウドダウンロードは制限あり
- WebDAV接続は会員限定

結論から言うと、**ちょっとしたファイルの受け渡しに使うなら無料でも全然いい**。ただし、動画や大容量ファイルをどんどん保存して使いたいなら、無料プランはすぐ溢れる。

## **グローバル会員とリージョナル会員の違い：日本ユーザーはどっち？**

PikPakには2023年7月から「グローバル会員」と「リージョナル（地域）会員」という区分が導入されている。

**グローバル会員（Global Premium）：**
- 日本・アメリカ・カナダ・ヨーロッパ主要国など33ヵ国以上のユーザー向け
- 最大ダウンロード速度：**20MB/s**（将来的にさらに向上予定）
- 世界中どこからでも同じ速度が保証される
- 料金は高め

**リージョナル会員（Regional Premium）：**
- 上記以外の国・地域のユーザー向け
- 最大ダウンロード速度：ファイルあたり**8MB/s**
- 先進国に滞在中はダウンロード速度が制限される
- 料金は安め（開発途上国向けに価格を抑えてある）

**日本からPikPakにアクセスすると、自動的にグローバル会員の価格が表示される。**操作は何もしなくていいし、購入画面を開けば適切な価格が出てくる仕組みだ。

ただし、VPNを長期間使っている場合や、海外の電話番号をアカウントに登録している場合は判定がズレることがある。その場合は日本の電話番号をアカウントに紐づけると修正できる。

## **Premiumが切れたらデータはどうなる？知っておきたいルール**

Premiumの有効期限が切れた後のデータについて、きちんと把握しておきたい人も多いと思う。

期限が切れると：
- アカウントは通常ユーザー状態に戻る（6GBの無料枠に戻る）
- 既存のファイルは閲覧・管理が引き続きできる
- 6GBを超える分があると「超過使用状態」になり、新しいファイルの追加ができなくなる
- 期限切れから7日後に、動画のオンライン再生とローカルへの高速ダウンロードが制限される

**重要なポイント：** 超過状態が続いた場合、6ヶ月の猶予期間（期限切れから4ヶ月＋猶予2ヶ月）を経て、古いファイルから自動削除が始まる。このルールは**2026年3月1日から適用**されているので、長期間放置するのは要注意だ。

## **よくある質問（FAQ）**

**Q：無料プランのまま使い続けることはできる？**
A：できる。6GBの枠の中で使う分には完全無料で使い続けられる。ただし動画の本格活用や大容量ファイルの保存をしたいなら、すぐ容量が足りなくなるだろう。

**Q：Premiumの料金は為替で変わる？**
A：USD（ドル）建て表示が基本。円で支払う場合は決済時の為替レートが適用される。App Store経由の場合は円建て価格が設定されている場合がある。

**Q：Premiumを解約するとすぐに使えなくなる？**
A：解約後も有効期間が終わるまでは使える。自動更新を止めると、期間終了後に無料プランに戻る。

**Q：招待コードは何度でも使える？**
A：招待コードは新規ユーザーが初回登録時に入力するもの。一度使ったらそのアカウントでは再使用できない。

**Q：日本語サポートはある？**
A：PikPakの公式サイトには日本語ページがあり、ヘルプセンターやFAQも日本語対応している。
